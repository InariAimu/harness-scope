# Cherry Studio 兼容

[文档索引](README.md) · [使用指南](USAGE.md)

适配器 `cherry` 只读 Cherry Studio 2.x 数据库及 WAL；默认位置由系统配置目录下的 `CherryStudio/Data/cherrystudio.sqlite` 决定。现有安装首次升级时发现数据库会添加并启用来源；之后用户删除或关闭来源不会自动恢复。普通聊天与 Agent 会话以独立身份列出，支持文本、思考和部分工具步骤；附件和会话删除尚未支持。

用量只读取 `ai_usage_record` 的语言模型逐次调用，不从消息统计再次计数。输入总量、非缓存输入、缓存读写及输出合计必须一致，推理数量也必须存在且不超过输出；不满足的记录保留诊断并重试，不覆盖或删除已采集事实。无关联消息的调用归入未关联会话。费用优先使用供应商报告的美元金额；Cherry 自行计算的费用不当作原生上报，按应用中匹配的供应商价表估算。缺少适用价格、计价汇率或时段依据时保持未知；模型参考价不代表实际账单。

Cherry 迁移的 `legacy-aggregate` 可能包含估算请求数，且缺少缓存拆分。按照已选择的统计口径，这些旧汇总不纳入统计，也不会作为扫描错误或阻止来源建立检查点。统计结果不包含这些未知历史用量，不能解释为实际用量为零。图像、向量和重排用量不属于当前语言模型统计范围；欠缺必要分类的逐次调用不计入并保留诊断以待重试。
