# 使用指南

[文档索引](README.md) · [供应商与订阅](PROVIDERS.md)

本页整理自原项目 README 的使用说明。安装依赖、源码启动和可执行文件构建见[开发与构建](DEVELOPMENT.md)。

## 首次使用

1. 在「应用」页检查已发现的工具和来源目录，按需添加目录并启用采集。
2. 在「用量」页选择时间、设备、工具、供应商或模型，查看汇总及请求明细。
3. 在「会话」页浏览本机内容；在「供应商」页按需配置余额查询和订阅信息。
4. 需要多设备汇总时，在「设置 → 多设备同步」连接自己的同步服务器。

左下角终端名称旁的编辑入口和「设置 → 通用 → 设备名称」都可修改设备名称。名称与稳定设备 ID 分开，改名不改变历史归属；下一次同步会发布新名称。设备筛选同时显示名称与短 ID，同名设备仍分别统计。

## 通用设置与 Windows 托盘

「设置 → 通用」中的选择、开关和外观调节即时生效并自动保存；设备名称、时区和采集间隔在回车或离开输入框时保存。保存失败会提示并恢复上次保存值。设置页不再提供右上角的统一保存按钮；网络页的「保存网络设置」和多设备同步页的「保存并同步」仍需显式提交，迁移仍需预览后确认。

Windows 桌面版在「通用 → 启动与关闭」提供：

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 开机自启 | 关闭 | 当前 Windows 用户登录后启动应用；关闭后移除自启注册 |
| 静默启动 | 关闭 | 下次启动只显示托盘，主窗口从一开始保持隐藏；与开机自启独立 |
| 关闭时最小化到托盘 | 开启 | X、Alt+F4 隐藏窗口，保留页面、输入和后台采集；关闭此项后关闭窗口退出应用 |

托盘左键点击或右键「打开 Harness Scope」恢复窗口；右键「退出」始终结束应用。再次启动已有进程时恢复原窗口，不重复启动采集。隐藏窗口仍保留 WebView，不代表释放全部界面内存。托盘创建失败时显示主窗口，关闭窗口正常退出。这些选项仅在当前设备生效，浏览器版不显示。

## 数据来源

默认目录用于初始发现；已经保存的来源以「应用」页配置为准。不要把同一份原生日志副本在不同设备上重复采集。

| 工具 | 默认来源／配置 | 注意事项 |
| --- | --- | --- |
| Claude Code | `~/.claude/projects`；支持 `CLAUDE_CONFIG_DIR` | JSONL 适配边界见 [Claude 说明](CLAUDE.md) |
| Codex | `CODEX_HOME` 或 `~/.codex` 下的活动与归档会话目录 | 初始 Fast 证据必须来自同一来源；见 [Codex 说明](CODEX.md) |
| OpenCode | `~/.local/share/opencode/opencode.db`；支持 `XDG_DATA_HOME`、`OPENCODE_DB` | 可填数据库文件或包含它的目录；只读 V1／V2 SQLite，迁移后的同会话不重复计数 |
| DeepSeek Harness | `DSH_HOME/sessions` 或 `~/.dsh/sessions` | 支持主目录、sessions 目录、单个会话目录或日志；见 [DSH 说明](DSH.md) |
| Cherry Studio | Windows 下 `%APPDATA%/CherryStudio/Data/cherrystudio.sqlite` | 只读普通聊天和 Agent 会话；仅采集可完整拆分的逐次调用，未知旧汇总不计入；见 [Cherry 说明](CHERRY.md) |
| GitHub Copilot | 手动配置 VS Code User 根目录 | 需先建立历史会话清单；使用[兼容导入工具](COPILOT_IMPORT_DESIGN.md#选择历史范围和执行导入) |

OpenCode 的早期 JSON 存储、分叉继承正文和 SQLite 附件图片没有完整适配。DSH 只支持已实现的 v0／v4 格式。未知版本、损坏或未完成的记录会诊断并重试，不把缺少数据解释为零用量。

OpenCode 用量采集只读取统计和计时所需字段；无关正文中的不合法字符不会使已知用量丢失。关键用量字段损坏时继续保留诊断和既有记录，来源或其依赖变化后自动重试，也可手动重新扫描。

## 应用采集与显示

「应用」页每个应用提供两个独立开关，切换后自动保存，仅在当前设备生效：

- **采集**：控制该应用所有目录的自动、手动及重建采集。关闭后从下一次采集起跳过该应用，已开始的采集会完成；历史用量与目录开关保留，重新开启后继续采集已启用的目录。
- **显示**：仅控制用量页和会话页的应用筛选项。关闭后该应用不再出现在筛选选项中，但「全部应用」的汇总、图表、请求明细与会话列表仍包含它；采集和同步继续按各自设置运行。

隐藏筛选项的应用仍保留在「应用」页，随时可以恢复显示。目录路径与目录采集开关仍需点击「保存目录」；只有应用采集和目录采集同时开启，才会扫描该目录。关闭采集后仍可阅读历史会话，但不能在本应用中删除它们，因为删除前需要先保存用量。

## 应用与供应商图标

点击「应用」页的应用图标，或「供应商」页品牌名称左侧的图标，打开悬浮选择条。预置按「品牌图标」「社区头像」「像素头像」分组，点击后立即保存；弹层不改变页面布局。

品牌图标保留 Claude、OpenAI、DeepSeek、OpenCode 和 GitHub Copilot。社区头像与像素头像各提供 Anthropic（Claude）、DeepSeek、ByteDance（Doubao）、Google（Gemini）、Zhipu（GLM）、OpenAI（GPT）、xAI（Grok）、Moonshot（Kimi）8 个选项，应用和供应商均可使用。普通头像背景透明，像素头像铺满方形背景，均为 128×128 PNG。这些可选头像基于 `assets` 中的社区拟人形象制作，不替换默认品牌标志，也不占用自定义素材库容量。

上传支持 SVG、PNG、JPG、WebP，文件最大 1 MB。默认居中裁剪为方形，可调整缩放和水平／垂直位置，也可选择「保留完整图片」添加透明留白。预览同时展示深浅背景；应用后尺寸不超过 128×128，小图不放大。SVG 保留矢量格式，普通图片保存为 PNG；SVG 仅支持静态图形、渐变、裁剪和蒙版，不支持脚本、外部资源或样式表，复杂图标可先导出为 PNG。

应用图标按应用 ID 配置，会统一更新用量与会话等展示位置。供应商图标默认使用品牌标志，自定义只作用于当前账号及其侧栏订阅项；同品牌的其他账号不受影响。

两类对象共用「我的图标」素材库，上传的相同内容自动复用。素材旁显示使用数量；「恢复默认」只解除当前绑定，只有未使用的素材可以删除。删除账号会释放其图标绑定，素材仍可复用。库最多保存 64 个自定义图标，并设有总容量限制，满时可删除未使用素材。

图标和绑定仅保存在本机数据库，不随用量／订阅历史同步，不影响账号凭据、查询配置、采集开关或历史数据。

## 统计口径

- 输入、输出、缓存读取和缓存写入分别统计；推理是输出子集，不再次加入总 Tokens。
- 费用区分原生报告、模型价表估算和未知。没有价格不等于免费；Copilot 兼容导入只保留可确认的 Token 维度，其余可能填 0，不能当作完整用量。
- 价格配置支持内置表、models.dev 导入及手动价格。实际使用的单价和来源随记录保存，更新价表不自动改写历史费用。
- 币种、手填汇率、侧栏今日指标、请求列显隐和图表样式在本机保存；显示换算不改变原始费用快照。
- Codex 同模型可分为 Standard、Fast 和档位未知；其他工具不会仅凭模型名进入该分组。速度和首字均需有效样本，规则见[计时说明](TIMING.md)。

统计分组使用设置中的 IANA 时区，时间范围控件使用查看设备的系统时区；跨时区查看时留意边界。历史日汇总的原日期和原时区另行保留，不能精确还原小时明细。

## 会话阅读与删除

会话支持搜索、按项目／时间分组、对话与工具步骤、内联图片、Markdown 导出和支持的恢复命令复制。列表摘要、分页正文与长工具输出分别读取；外部图片文件引用和工具附件图片尚未完整支持。

删除入口由适配器能力决定：当前 Claude Code、未压缩的 Codex 会话支持；Codex 压缩会话、OpenCode、DSH 和 Copilot 不提供本应用内删除。删除前来源须稳定至少 60 秒，应用先采集并保存用量；采集失败则取消删除。正文删除后历史统计仍保留。

跨设备同步传输统计事实，不传输会话正文，因此其他设备的统计不会自动带来可阅读的完整对话。

## 多设备同步

先按[服务器说明](../server/README.md)部署服务，再在各设备「设置 → 多设备同步」填写相同服务器地址与令牌。远程地址使用 HTTPS，只有 loopback 允许明文 HTTP。

每台设备保存自己的 ID、事实和持久待传队列；断网后可继续使用本机数据，恢复连接后增量同步。全部设备视图包含已下载的其他设备记录，不重复加入本机镜像。重命名设备不重置 ID，恢复同一设备备份时也应保留其身份。

请求用量与共享订阅历史是两个通道。同步请求并不会自动关联账号；额度历史需要按[共享订阅步骤](PROVIDERS.md#跨终端订阅历史)在各端绑定。完成一次同步只说明已交换当前已知数据，不保证离线设备已上传全部用量。

## CC Switch 历史迁移

在「设置 → 数据迁移」选择 schema v20 数据库或 SQLite 备份，填写稳定旧来源 ID、分界自然日和旧系统时区。先预览对账，再提交同一快照摘要。源库只读，导入原子提交。

- 分界日前采用旧统计，分界日及之后采用原生日志；更早日志仍可用于累计基线和继承关系。
- 重导相同快照不累加；同一来源换快照或重叠来源会拒绝。
- 旧日汇总不能还原请求明细；部分覆盖一个汇总日的查询排除该日，不按比例猜测。
- WebDAV／S3 配置同步快照没有用量数据；不直接执行外部 SQL 备份或恢复整个 CC Switch 数据库到本应用。

## 网络设置

「设置 → 网络」统一控制同步、余额／额度、自定义查询和 models.dev 下载。

| 模式 | 行为 |
| --- | --- |
| 跟随系统 | 优先进程代理环境变量，再使用系统手动代理，并遵循绕过规则；不解析 Windows PAC |
| 指定代理 | 支持无认证的 HTTP、HTTPS、SOCKS5／SOCKS5H 地址；loopback 直连，代理失败不自动回退 |
| 直连 | 禁用这些应用请求的代理 |

可保存前测试 models.dev 连接。配置仅在本机生效，不修改操作系统代理；独立运行的编程工具和外部浏览器仍使用自身设置。Codex 额度查询子进程会接收所选代理策略。

## 数据与备份

Windows 桌面数据库默认位于 `%APPDATA%/dev.inariaimu.harness-scope/harness-scope.db`，与 CC Switch 独立。数据库包含设备身份、统计、设置和同步状态；通过 SQLite Backup API 生成一致性备份，或在应用完全停止后备份数据库及必要的 WAL 状态。

供应商 Key 单独存放在数据库旁的 `.provider-keys` 目录。Windows 使用当前用户 DPAPI，Unix 使用目录／文件权限保护；仅备份数据库不包含这些 Key，换 Windows 用户或设备后需重新填写。Codex 登录仍由 Codex 自己管理。

Go 规则和 Codex 参考配置的旁文件是本机草稿；外部修改后需在界面载入、校验并应用。升级前保留数据库与旧程序；数据库已升级时回退应用须同时恢复相应旧库。服务器备份与实例恢复另见[服务器说明](../server/README.md)。
